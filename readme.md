# Hermes Session Viewer

Read-only web viewer for [Hermes Agent](https://hermes-agent.nousresearch.com/) conversation sessions.

![Screenshot](screenshot.png)

- Responsive layout
- Light & dark theme
- View message & reasoning with Markdown rendering
- View tool call with optimized rendering such as code highlighting
- View session meta such as system prompt

## Usage

```sh
git clone https://github.com/kidonng/hermes-session-viewer
cd hermes-session-viewer
pnpm install
pnpm build
pnpm start
```
