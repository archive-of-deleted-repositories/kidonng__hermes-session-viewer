# Hermes Session Viewer

Read-only viewer for [Hermes Agent](https://hermes-agent.nousresearch.com/) conversation sessions.

## Features

- List sessions from `~/.hermes/sessions/sessions.json`
- Render session from `~/.hermes/sessions/<session_id>.jsonl`

Explore the data for data schema, examples etc.

## Interface

### General

- Left sidebar: session list
- Top right: session meta
- Right: messages

### Messages

- Timestamp
- Copy raw button
- Render messages & reasoning as Markdown
- Collapsible reasoning with global toggle

### Tool Calling

- Collapsible with global toggle
- Preview for most important call argument without expanding
- Group corresponding tool call & result together
- For result with status-like property, use a error background when it fails
- Optimize display and usefulness for specific tools, examples:
    - Highlight `terminal` tool `command` as shell code
    - Render `browser_vision` tool `analysis` as Markdown
    - Render `browser_navigate` tool `url` as link

## Tech Stack

- Node & pnpm
- React & TanStack Start
- Tailwind & daisyUI
- Remark & Shiki

### Notes

- Prioritise simple, reusable components & utils
- Prefer native elements, like `<details>` for collapse
